ℹ️ How it works

The tool fetches map tiles for the area and zoom levels you choose, cuts them to the tile size the widget expects, and lays them out as MAPS/<type>/<zoom>/<x>/<y>.png — each map type in its own folder, listed in MAPS/sets.txt so the widget can switch between them. It also writes WIDGETS/SatMap/main.lua, already matched to your tile size and zoom range.

On Chrome or Edge you can point it at your SD card (or any folder) and it writes the files there directly — existing tiles are skipped, so you can extend an area later. On other browsers it hands you a single ZIP to unzip onto the card.

Copy the MAPS and WIDGETS folders to the root of the SD card, reboot the radio, then add the SatMap widget to a full-screen layout. The setup guide has the full steps.
